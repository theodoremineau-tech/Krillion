# The Trench

Krillion-style daily rare-answer trivia for a friend group. Full context: `HANDOFF.md`.

## Rules

- Plain HTML/CSS/JS frontend in `public/`, no framework, no bundler. Keep it that way.
- The server (`server/game.mjs`) is the source of truth for time, grading and scores. Never move grading or answer sheets to the client; `server/questions/` must never be served.
- `server/core.js` is pure logic shared by the Netlify Function, the dev server, the practice build and the tests. No I/O in it.
- Storage goes through the `{get,set,del,list}` store interface so Netlify Blobs, the dev server's JSON file and the practice in-memory store stay interchangeable.
- After any change to `server/questions/` or `server/core.js`, run `npm test`. Both suites must pass. Add a case to `test/matching.js` for every matching bug fixed.
- `server/bank.mjs` is generated by `server/build-bank.mjs`; don't hand-edit it. Same for `server/questions/zz_expanded.js` (from `tools/expand/`, see HANDOFF "Answer bank depth") and `server/wordlist.js`.
- After any matcher change, run `node tools/eval-matching.js` and don't let recall drop or false accepts rise (Oct 2026 baseline: 95.5% / 0.6%).
- Don't copy Krillion's code or answer data; only match its behaviour.
- Rewording a prompt changes its id (hash of the text). That's acceptable; dives store their own prompt ids.
- Tiers are fixed per answer and never depend on what other players typed.
- Do not touch Teddy's Daily Briefing Netlify site; this game deploys from the `theodoremineau-tech/Krillion` repo only.

## Commands

```
npm install
npm run dev        # localhost:8787, data in .data/
npm test
npm run practice   # dist/trench-practice.html
```
